# Roadmap

## 1. Phase actuelle

Le projet est en phase de cadrage stratégique, produit et business.

Objectifs immédiats :

- clarifier la documentation
- stabiliser le positionnement
- figer le périmètre MVP
- préparer le modèle métier

---

## 2. Étapes logiques recommandées

### Phase 1 — cadrage propre

- consolider le dossier vision / stratégie
- clarifier le positionnement de l’entreprise
- recadrer l’offre MVP
- consolider le business model

### Phase 2 — formalisation produit

- définir le modèle métier
- préciser le parcours utilisateur
- écrire les règles de gestion principales

### Phase 3 — cadrage technique

- définir l’architecture logique
- préciser l’architecture technique du MVP
- choisir les conventions de structuration

### Phase 4 — validation terrain

- tester la perception de l’offre
- tester le pricing
- tester la compréhension de la maquette preview
- tester la posture commerciale

### Phase 5 — exécution MVP

- spécification des premières features
- implémentation du socle
- preview
- validation
- publication
